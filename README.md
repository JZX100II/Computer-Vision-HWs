# Computer Vision Coursework

Assignments completed for a Computer Vision course using Python, OpenCV, NumPy, and Matplotlib.

## HW1
- Image filtering and sharpening.
- Histogram analysis and enhancement.
- RGB and HSV color spaces.

## HW2
- Fourier transform and frequency-domain filtering.
- Image reconstruction and denoising.

## HW3
- Edge detection and line detection.
- Circle detection using Hough Transform and RANSAC.

## HW4
- Color segmentation and pseudocolor visualization.
- Edge detection methods and comparison.

## HW5
- Harris, SIFT, and ORB feature detection.
- Feature matching and panorama stitching.

## Requirements

- Python 3
- OpenCV
- NumPy
- Matplotlib

Install dependencies:

```bash
pip install opencv-python numpy matplotlib
```
